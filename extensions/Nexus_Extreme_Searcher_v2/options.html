Nexus Extreme Searcher v2

Nexus vyhľadáva video zdroje. Jackett a Prowlarr dopĺňajú torrenty; SearXNG prehľadáva verejne indexované stránky.

Lokálne služby

Overí Nexus a zistí, či má nastavený Jackett, Prowlarr a qBittorrent. Nečíta ani neukladá API kľúče.

Nexus import

Vyplň len keď je v Nexus `.env` nastavený `NEXUS_BRIDGE_TOKEN`; inak nechaj prázdne.

Torrenty

Otvor `http://127.0.0.1:9117`, v Jackett skopíruj API Key.

Po inštalácii otvor `http://127.0.0.1:9696` → Settings → General → API Key.
